## Requirements
1. NPM
2. Composer
3. PHP >8.2

## First time setup
1. Run 'npm install --global yarn'
2. Run 'composer install'
3. Run 'yarn'
4. Run 'npm run dev'
5. Make a copy of .env.example and rename as .env
6. Run 'php artisan key:generate'
7. Run 'php artisan migrate:fresh --seed'

## Run the system
6. Run 'php artisan serve'
